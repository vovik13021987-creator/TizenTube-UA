# Як завантажити TizenTube-UA у свій GitHub з Android

Репозиторій: https://github.com/vovik13021987-creator/TizenTube-UA

## Завантаження файлів
1. Відкрий репозиторій у браузері й переконайся, що він Public.
2. Натисни **Add file → Upload files**.
3. Важливо: GitHub через мобільний браузер може не завантажити цілу папку з ZIP автоматично. Спочатку розпакуй цей ZIP на телефоні у файловому менеджері або архіваторі.
4. Завантаж вміст папки проєкту в корінь репозиторію, а не сам ZIP. Має з'явитися `package.json`, `README.md`, `mods/`, `service/`, `standalone/`, `.github/` та інші файли.
5. Натисни **Commit changes**.

## Важливі обмеження
- Це вихідний код, не готовий для прямого встановлення у TizenBrew.
- Після завантаження потрібно налаштувати збірку. Для модуля потрібні сумісні `dist/userScript.js` і `dist/service.js`.
- Не вставляй URL репозиторію в TizenBrew, доки не опубліковано сумісний модуль/реліз.
- Цей форк не синхронізується автоматично з оригінальним репозиторієм. Це захищає твої правки від автоматичного перезапису, але сумісність з майбутніми версіями YouTube/TizenBrew все одно треба перевіряти.
- Не додавай до GitHub паролі, токени, сертифікати підпису або інші секрети.
