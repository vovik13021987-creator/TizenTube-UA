# Українська локалізація та меню тривалого натискання

У цьому архіві внесено зміни до вихідного коду TizenTube:

- доповнено `mods/translations/resources/uk.json` відсутніми ключами локалізації та перекладено багато нових пунктів налаштувань, повідомлень і меню;
- у `mods/ui/longPressMenu.js` додано «Не цікавить» і «Не рекомендувати канал» до стандартного порядку пунктів меню;
- у `mods/features/adblock.js` виправлено логіку відновлення цих дій: тепер наявність однієї дії YouTube не блокує додавання другої, якщо її немає.

## Перевірки

- JSON українського перекладу розбирається без помилок.
- `node --check` пройшов для змінених JavaScript-файлів.
- Перевірено наявність ключів перекладу відносно `en.json`.
- Повну збірку `dist/userScript.js` не вдалося виконати в цьому середовищі: залежності Rollup не встановилися. Отже, це архів вихідного коду, а не готовий для встановлення реліз. Перед використанням потрібно зібрати проєкт командою `cd mods && npm ci && npm run build`.
- Наявність пункту в меню залежить від того, чи передає YouTube потрібні дані для конкретної плитки. Змінений код не може гарантувати всі дії для кожного типу плитки без перевірки на телевізорі.
